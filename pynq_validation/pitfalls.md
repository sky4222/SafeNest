# 踩坑与定位

| 触发条件/观察 | 排查步骤 | 验收/失效条件 |
|---|---|---|
| Overlay加载或DMA操作后掉线 | 停止重复运行；核对同次bit/HWH、必需IP、BD时钟复位；检查辅助复位极性，确认没有其他内核重配PL | 重初始化后先旁路再参考比对；文件检查不能证明时钟/复位正确 |
| 同一录音滤波前后分类差别大 | 固定同一窗口，核对声道/采样率/dtype/归一化；导出中间.npy比较 | 对齐后再评价算法；不同训练前端不套用固定参数 |
| record返回但静音 | 播放解码后的缓冲，比较安静/说话RMS；查输入选择、插头制式、偏置 | 固定声源重测；换芯片需查自身手册 |
| 一启用报警手机就通知 | 区分arm使能与trigger；去掉临时arm/disarm替换；真实新触发走回调 | 不报警与报警序列分别测试；发布返回不证明手机接收 |
| 时序摘要通过但Methodology严重警告 | 核对主时钟、生成时钟和端口约束，逐条读规则原文 | 修复后重新实现；不降级警告，不随意false_path |
| 表格有指标但无原始记录 | 标记日志字段、计时区间、输入、样本数和构建hash | 找不到就重测；仿真、主机、实体板分别标注 |

来源：上述条目均从本项目协作观察提炼。它们是排查入口，不是所有同类故障的唯一原因；本次未修复所有历史问题。
