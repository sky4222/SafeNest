# 可复用接口契约模板

适用：PYNQ驱动编写、DMA联调、换Overlay或移植板卡前。复制本表并从实际工程填写；该表本身不操作硬件。

| 项目 | 需要填写的内容 |
|---|---|
| 构建身份 | 源码提交、工具版本、bit/HWH文件名与SHA256、同次导出依据 |
| 目标平台 | 板卡、完整器件、PYNQ/Python版本、所需内核驱动 |
| IP与寄存器 | HWH实例路径、寄存器名称/偏移、位域、读写副作用 |
| 数据表示 | 输入输出dtype、位宽、符号、定点缩放、通道排列、字节序 |
| 传输长度 | 样本数与字节数换算、最大块长、对齐限制 |
| 流协议 | TDATA/TKEEP/TLAST、背压支持、谁生成帧末标志 |
| 时钟与复位 | 时钟来源/频率、跨时钟域、复位极性及释放条件 |
| 驱动顺序 | 缓冲区分配、缓存同步、启动先后、完成判据、异常恢复 |
| 参考对齐 | 同一输入、算法状态、窗口起点、群延迟、边界与输出长度 |
| 判定标准 | 定点精确相等或浮点误差预算、旁路/功能测试预期 |

使用方法：先填接口，再运行元数据检查，随后按workflows.md做旁路和参考比较。换板时重新填写平台、时钟、管脚及驱动要求；原bit不能随模板直接迁移。

经验来源：本项目Overlay切换、FIR定点及分块DMA联调。已验证效果：这些字段可对应本项目已使用的接口与自检步骤；模板尚未在第二个实体工程完成移植。失效条件：接口资料错误、遗漏IP内部限制或参考算法与实际版本不一致。
